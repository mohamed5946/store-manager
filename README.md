# 🏢 نظام الإدارة المتكامل (ERP System)

نظام إدارة متكامل لإدارة المبيعات والمشتريات والمخزون والأرباح.

---

## 📦 متطلبات التشغيل

- **Node.js** (v18 أو أحدث): https://nodejs.org
- **Windows 10/11** (x64)

---

## 🚀 طريقة التثبيت والتشغيل

### الطريقة الأولى: التشغيل المباشر (للتجربة)

```bash
# 1. افتح Command Prompt أو PowerShell في مجلد البرنامج

# 2. ثبّت المكتبات
npm install

# 3. شغّل البرنامج
npm start
```

### الطريقة الثانية: إنشاء ملف تثبيت (.exe)

```bash
# 1. ثبّت المكتبات
npm install

# 2. ابني ملف الإعداد
npm run build

# 3. ستجد ملف الإعداد في مجلد: dist/
#    اسمه: نظام الإدارة المتكامل Setup X.X.exe
```

## 💾 حفظ البيانات

البيانات محفوظة تلقائياً في:
```
C:\Users\[اسم المستخدم]\AppData\Roaming\erp-system\data\
```

### النسخ الاحتياطي التلقائي (جديد في هذه النسخة)
- عند كل تشغيل، البرنامج ينسخ صورة كاملة من ملفات الداتا إلى مجلد مؤرخ داخل:
```
...\erp-system\data\backups\<تاريخ ووقت التشغيل>\
```
- يحتفظ بآخر **7 نسخ** فقط، والقديم يتمسح تلقائياً.
- **الاسترجاع يدوي:** لو ملف داتا تلف، اقفل البرنامج، انسخ ملفات النسخة السليمة فوق مجلد `data`، وشغّل تاني.

### أمان الكتابة (جديد في هذه النسخة)
- كل حفظ يتم **بكتابة ذرية** (ملف مؤقت ثم إعادة تسمية)، فلو الجهاز طفى في نص الحفظ، الملف الأصلي يفضل سليم.
- البيع لا يتم لو الكمية المطلوبة أكبر من المخزون المتاح (مع مراعاة التعديل: كمية الفاتورة القديمة تُحسب كمتاحة).

## 🔧 المميزات التقنية

- تطبيق Electron يعمل على Windows بدون إنترنت
- قاعدة بيانات JSON محلية (لا تحتاج SQL)
- واجهة عربية كاملة RTL
- حساب الأرباح تلقائياً
- تحديث المخزون تلقائياً مع كل عملية
